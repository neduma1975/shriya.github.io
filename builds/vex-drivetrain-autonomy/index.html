VEX Drivetrain Testing + Bézier Autonomy

TL;DR

Built three identical drivable testbeds (tank vs X-drive vs 6-motor mecanum) to compare sprint speed and current-logged push force, picked mecanum, then drove it with a C++ odometry + Bézier planner.

📄 Drivetrain & autonomy PDF (2 pp)↗

✓ 6-motor mecanum selected from 3 testbeds; field-centric odometry planner

Role: Co-founder, Captain, Designer & Programmer — 9-member team (Bobaionics 12478X)

01 / Problem

Pick a drivetrain base that balances cycle speed and scrum pushing force, then execute simultaneous translate-and-rotate autonomous routines without stop-turn-drive penalties.

02 / Design process

  1. Built three full-width testbeds: 6-wheel tank, X-drive, 6-motor mecanum (same brain/IMU placement for equal weight distribution)
  2. Timed straight-line sprints under load and ran barrier-push tests with motor current logging to compare usable stall force
  3. Integrated X/Y tracking wheels → continuous X/Y/θ pose → Bézier-curve planner with rolling lookahead; tuned in jerry.io sim before real-robot drift correction

03 / Build

6-motor mecanum chassis with 45° roller geometry and traction tuning; orthogonal X/Y odometry wheel stack; C++ field-centric waypoint routines around stakes, rings, and drop-off.

04 / Testing & results

Selected base
6-motor mecanum (strafe + competitive push)

05 / What I learned

Controlled A/B testbeds settle drivetrain debates fast; sim-first Bézier path tuning reduced on-field autonomous debugging.
